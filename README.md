# Каршеринг MVP

## Запуск
## Если требуется изолированное окружение, то пользуемся данными командами:
`py -m venv venv`
`venv\Scripts\activate`
## Даллее запускаем:
1. `pip install -r requirements.txt`
2. `python app.py`
3. Открыть http://localhost:5000
